# Certificates

Once a published event ends, every ticket checked in at its door has a
certificate. The ticket opens with **Tu certificado**, and **Ver mi
certificado** goes to the certificate's own link:

```
https://up.rising.sh/c/Xq3vT9bLk2RmW8pZc4HnAe
```

The page shows one landscape sheet in the event's colors:

```
CERTIFICADO · HACKATHON
Valeria Quispe Huamán
asistió a
Mini hackathon de ML para física
del 20 al 21 de noviembre de 2026 · Facultad de Ciencias Físicas, UNMSM
                       Verifica este certificado en up.rising.sh/c/Xq3v…
```

**Imprimir o guardar PDF** prints it on one A4 landscape page. The printed
address lets a reader of the paper open the same certificate. Search engines do
not index it.

## Roles

Each person on the event's **Equipo** tab has a certificate of their own, with
or without a ticket. Once the event is over, the tab shows a **Certificado**
link beside each name; send it to them. See [Team](add-an-event.md#team).

The line under the name says what the person did:

| Role       | Line              |
| ---------- | ----------------- |
| none       | asistió a         |
| Organiza   | organizó          |
| Ponente    | fue ponente en    |
| Mentor     | fue mentor en     |
| Jurado     | fue jurado en     |
| Voluntario | fue voluntario en |

A checked-in ticket whose email holds a role names that role. With several
roles, it names the first in the order of the table.

## When a certificate answers 404

- The event has not ended yet, or it is a draft.
- The ticket was never checked in, or its check-in was undone. Checking it in
  again brings back the same link.
- The role was removed from the **Equipo** tab.
